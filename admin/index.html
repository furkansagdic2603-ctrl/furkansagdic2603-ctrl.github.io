Metni düzenleyin, HTML dosyasını indirin ve aşağıdaki adımlarla yayımlayın.

Yayımlama

  1. GitHub deponuzu açın ve Add file → Create new file seçin.
  2. Dosya adı alanına indirme sonrası gösterilen kategori/yazi-adi/index.html yolunu yazın.
  3. İndirilen HTML dosyasını bir metin düzenleyicide açın, tamamını kopyalayıp GitHub'a yapıştırın; Commit changes ile kaydedin.
  4. Birkaç dakika içinde yazı, kategori sayfası, ana sayfa, arşiv ve arama sonuçlarına eklenir.

Bu editör giriş ekranı değildir; yayımlama için GitHub hesabınızla oturum açmanız gerekir. Taslaklar bu cihazda otomatik saklanır.
